# 0001: Pin OCaml 5.5.1

Date: 2026-10-13

## Context

bactrian ships a browser toplevel built with js_of_ocaml. js_of_ocaml-compiler 6.4.1, the current release, supports OCaml below 5.6. The rest of the toolchain (dune 3.24.2, Eio 1.6, cohttp-eio, tls-eio) works on 5.5.1.

## Decision

Development uses a project-local opam switch with `ocaml-base-compiler.5.5.1`, and CI installs the same compiler. `dune-project` declares `ocaml >= 5.4`, the floor for `Result.Syntax`.

## Consequences

Moving to OCaml 5.6 waits for a js_of_ocaml release that supports it. On macOS hosts whose Command Line Tools SDK is newer than the running OS, the switch must be built with `SDKROOT` pointing at an SDK that matches the OS, otherwise the compiler enables `pipe2` and tools that call `Unix.pipe` crash.
