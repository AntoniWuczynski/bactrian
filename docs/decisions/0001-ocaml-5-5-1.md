# 0001: Pin OCaml 5.5.1

Date: 2026-10-13

## Context

OCaml 5.5.1 is the current release. Every library bactrian plans to use (dune 3.24.2, Eio 1.6, cohttp-eio, tls-eio, js_of_ocaml-compiler 6.4.1) supports it, and js_of_ocaml-compiler 6.4.1 does not yet support OCaml 5.6.

## Decision

Development uses a project-local opam switch with `ocaml-base-compiler.5.5.1`, and CI installs the same compiler. `dune-project` declares `ocaml >= 5.4`, the floor for `Result.Syntax`.

## Consequences

Moving to OCaml 5.6 waits until the libraries above support it. On macOS hosts whose Command Line Tools SDK is newer than the running OS, the switch must be built with `SDKROOT` pointing at an SDK that matches the OS, otherwise the compiler enables `pipe2` and tools that call `Unix.pipe` crash.
